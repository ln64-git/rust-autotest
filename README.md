# 🧪 Rust AutoTest

Automatically run your Rust tests on every file save — powered by VS Code’s native Testing API and `cargo test`.

---

## ✨ Features

- ✅ Automatically runs `cargo test` whenever you save a `.rs` file

---

## 🚀 Usage

1. Install the extension in VS Code
2. Open a Rust project
3. Save any `.rs` file
4. Watch your tests **auto-run** in the VS Code Testing sidebar

---

## 🧰 Commands

| Command | Description |
|--------|-------------|
| `Rust AutoTest: Toggle On/Off` | Enable or disable AutoTest |
